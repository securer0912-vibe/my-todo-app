# 📝 나의 할 일 목록

HTML, CSS, 바닐라 JavaScript로 만든 간단한 할 일(Todo) 관리 웹 앱입니다.
빌드 과정이나 외부 라이브러리 없이 브라우저에서 바로 실행됩니다.

## 주요 기능

- **할 일 추가**: 입력 후 `추가` 버튼 또는 Enter 키
  - 빈 값과 이미 등록된 할 일은 추가되지 않고 안내 메시지가 표시됩니다.
- **완료 표시**: 체크박스로 완료/미완료 전환
- **삭제**: 항목별 `삭제` 버튼
- **필터**: 전체 / 진행중 / 완료
- **완료된 항목 일괄 삭제**: 완료된 항목이 있을 때만 활성화
- **개수 표시**: 전체 할 일 개수와 완료 개수
- **자동 저장**: `localStorage`에 저장되어 새로고침해도 목록이 유지됩니다.

## 실행 방법

1. 저장소를 내려받습니다.

   ```bash
   git clone https://github.com/securer0912-vibe/my-todo-app.git
   ```

2. `index.html`을 브라우저로 엽니다. 별도의 서버는 필요 없습니다.

## 파일 구조

```
my-todo-app/
├── index.html   # 페이지 구조
├── style.css    # 스타일
└── main.js      # 할 일 추가·완료·삭제·필터·저장 로직
```

## 기술 스택

- HTML5
- CSS3
- JavaScript (ES6+, 프레임워크 없음)
- Web Storage API (`localStorage`)
